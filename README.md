# Efjord & Stetind Resort – romfordeling

Dashboard for romfordeling i juli og august 2027. Opprett hytter, rom og senger, og reserver senger ved å dra over ledige netter.

## Delte data
Alle med lenken ser de samme dataene. De ligger i `data.json` på branchen `data` (ikke `main`, så GitHub Pages bygges ikke på nytt ved hver endring).

For å redigere må man låse opp siden med en *fine-grained personal access token* som bare har tilgang til dette repoet:
- Repository access: kun `efjord-stetind-resort`
- Permissions → Contents: Read and write

Nøkkelen limes inn i siden og lagres bare i nettleseren på den enheten. Den ligger aldri i koden.
