# Efjord & Stetind Resort – romfordeling

Dashboard for romfordeling i juli og august 2027. Opprett hytter, rom og senger, og reserver senger ved å dra over ledige netter.

Data lagres i nettleseren (localStorage). Bruk «Rediger hytter → Eksporter/Importer» for å ta sikkerhetskopi eller flytte data mellom enheter.
